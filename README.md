## Intellivision Master Component Keyboard

Technical details for the 2609 computer.

## Reconstruction discipline

This project starts with the original machine's engineering intent, not a modern replacement design. Before proposing a recast, extension, or machine-intelligence use, we must:

1. reconstruct the original system's purpose;
2. trace the causal path by which an action becomes visible on screen;
3. establish what each processor, memory bank, and video subsystem contributes to that path; and
4. distinguish demonstrated evidence from inference.

No new architecture may silently truncate, replace, or assign meaning to an original feature before that feature is understood.

The first reconstruction, source-confidence assessment, and machine-intelligence recast are in [docs/FIRST-PASS-TECHNICAL-FOUNDATION.md](docs/FIRST-PASS-TECHNICAL-FOUNDATION.md).

## Archaeology

* The MAME material already supports a clear architectural split: the original CP1610/STIC console remains present, while the Keyboard Component adds an independent 6502 text-computing subsystem connected through dual-port memory.
